# 原始资料契约

所有机构、车辆、单据和设备均为本地合成，不来自新闻中的真实企业，也不声称新闻发生过这些事件。

称重动作身份是source/id/revision，重复身份不自动覆盖；cancel指定完整身份。replaces声明替代原修订，不表示这是又一次外部收集。重量为十进制kg，保留三位，未注明损耗时拆并各边应守恒；无依据的数量缺口保留争议，不自动补平。
transforms同id为一轮拆并，各行表达一个父批向一个子批转移的量，不代表新增物料。允许父批部分剩余、子批多来源，环不构成合法批次关系。legs的side区分装运与收货，双方按peer_source/peer_id引用对端，修订须明确；仅一端就绪不证明已到站。sales是外部出库，不是内部运输。
每行day为Asia/Shanghai业务日。原始动作可在不同日期到仓，动作发生日不随抵达日变更；输入动作按actions.json的step顺序提供，step不是仓库发布号。

seed.json与同名Parquet保存相同的输入值，actions.json中的后续动作尚未处理。inventory.json只校验原件物理完整性，不是仓库目录或业务结论。所有后续仓表与接口均待开发，源码不规定其架构。

source是业务系统命名空间，不自动等于station。transforms.station为实际分拣站，仅能消费该站有依据可用的父批数量，批次拆并不隐含跨站运输。初始LS由另一个系统登记在N站，尚未配齐的外部收货引用本身不增加其可用余额。
